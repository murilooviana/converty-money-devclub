## 📑 Sobre o Projeto

O **Convert Money** é um conversor financeiro desenvolvido durante a jornada de aprendizado no **DevClub**. O projeto permite converter valores em **Real Brasileiro (BRL)** para as principais moedas do mercado mundial e criptomoedas de forma simples e visual.

A interface foi projetada em **Dark Mode** com detalhes em dourado, proporcionando um visual elegante e focado na experiência do usuário.

<br />

---

## ✨ Funcionalidades

- 💵 **Conversão Dinâmica**: Converte valores instantaneamente de BRL para:
  - 🇺🇸 **Dólar Americano** (USD)
  - 🇪🇺 **Euro** (EUR)
  - 🇬🇧 **Libra Esterlina** (GBP)
  - ₿ **Bitcoin** (BTC)

- 🌐 **Formatação Internacional**: Uso da API nativa `Intl.NumberFormat` para aplicar os símbolos monetários e pontuações exatas de cada país/moeda.

- 🔄 **Reatividade Visual**: Troca de bandeira, nome da moeda e recálculo automático ao mudar a seleção ou clicar no botão **Converter**.

Este projeto foi construído utilizando as seguintes tecnologias:

- **HTML5**: Estruturação semântica de formulários e caixas de exibição.

## 🚀 Como Executar o Projeto

1. **Clone este repositório**:
   ```bash
   git clone https://github.com/murilooviana/converty-money-devclub.git
   ```

2. **Acesse a pasta do projeto**:
   ```bash
   cd converty-money-devclub
   ```

3. **Abra a aplicação**:
   - Dê um duplo clique no arquivo `index.html`, ou
   - Execute usando a extensão **Live Server** no seu VS Code.
